How to use it

Keep your keyboard. The bubble stays while the keyboard is up. Copy lives in History, not on the bubble.

You doWhat happens
Tap the bubbleListening starts
SpeakWords can show on the bubble if that setting is on
Tap again or DoneStop, clean, insert
HoldTalk while holding. Release inserts
XThrow away
Say “press enter” at the endInsert, then send
DragMove it. While the keyboard is up, it stays on screen

Dictionary vs snippet

Dictionary changes one word. Snippet pastes a whole block when you say an exact trigger.

History

Open the app → History. Copy, share, or delete there. Settings: keep, wipe in 24 hours, or never save.

If the bubble is gone

  1. Normal text field? Not a password or bank app?
  2. Keyboard up?
  3. Accessibility still on? Force-stop turns it off.
  4. Mic allowed?
