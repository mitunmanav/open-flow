## Honest pipeline (no cheat)

Wispr Android = cloud grammar. We **cannot** clone that without a model.

**Do:**
- API 33 `EXTRA_ENABLE_FORMATTING` — Accurate = quality, Fast/Balanced = latency (already in SttTuning)
- StyleApplicator only: end punct + caps + informal expand + custom replace
- Tests: same raw string → 5 styles **different** and High still runs style after hedges
- Dictionary = replace a **word** (`API` → `Application Programming Interface`)
- Snippet = say **exact trigger** → paste a **block** (`addr` → full address)

**Do not:** new filler/hedge word dumps, fake “grammar engine”.

### Task A — Bubble align + copy + shapes

**Tests first** (`BubbleGeometryTest`):

```kotlin
@Test
fun idle_circle_is_square() {
    val (w, h) = BubbleGeometry.overlaySizePx(listening = false, density = 2f, shape = "circle")
    assertThat(w).isEqualTo(h)
}

@Test
fun idle_dot_smaller_than_circle() {
    val c = BubbleGeometry.overlaySizePx(false, 2f, "circle")
    val d = BubbleGeometry.overlaySizePx(false, 2f, "dot")
    assertThat(d.first).isLessThan(c.first)
    assertThat(d.first).isEqualTo(d.second)
}
```

Change `overlaySizePx` to take `shape`. Circle = 52dp square. Dot = 28dp square. Pill/listen = 240×52.

XML: `bubble_icon` `layout_gravity=center`, `scaleType=center`, parent gravity center. Copy chip: show label “Copy” (already in service) + keep icon aligned.

Haptics: insert → `CONFIRM`, cancel → `REJECT` if API 30+ else `CONTEXT_CLICK` / `LONG_PRESS`.
