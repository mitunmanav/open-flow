Where this is going

A GitHub sideload today. Dates are not promises — direction is. Current app: v0.1.9, Sep 2026.

Now

  • Floating bubble that inserts into any text box. Not a keyboard.
  • Dictionary, snippets, and styles. Voice edits like “strike that”.
  • Local history with copy, share, and 24-hour auto-clear.
  • Optional fully-offline Whisper on phone.

Next

  • More install paths tested, fewer scary screens.
  • Better offline accuracy out of the box.
  • F-Droid listing.

Later, only if we mean it

  • Play Store — needs an Accessibility declaration and video. Hard and slow.
  • More languages.

Not planned

  • Becoming a keyboard.
  • Accounts, ads, analytics.
  • Calling this a Wispr clone.
