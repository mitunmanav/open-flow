# F10 Flow Bubble (Wispr Android style)

**Goal:** Dictation via floating bubble + accessibility insert text. **Not** a keyboard IME.

**How Wispr works (verified docs):**
- Floating bubble over apps / near keyboard
- Accessibility: detect focused text field, insert transcript
- Overlay: TYPE_ACCESSIBILITY_OVERLAY (or SYSTEM_ALERT_WINDOW)
- Keep user's normal keyboard

**Security:**
- Accessibility only for focus detect + text insert (disclose in UI)
- Skip password / phone fields
- No INTERNET still
- Mic runtime only when listening

**Files:**
- `bubble/FlowAccessibilityService.kt`
- `res/xml/accessibility_service_config.xml`
- Remove IME as primary; disable IME service in manifest or leave dormant
- MainActivity setup: enable accessibility + optional overlay
