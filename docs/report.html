Found a bug? Tell us.

GitHub only. Never put personal information in a report.

Open an issue Ask a question

Include

  • App version, from Settings
  • What you tapped, and what you expected
  • Phone brand + Android version, if you know them
  • A cropped screenshot, if it is a layout bug

Leave out

  • Passwords, medical notes, bank screens
  • Your name, email, or phone number
  • Device serials and full logs from other apps

Security hole? Use the repo Security tab — never a public issue.
