Install

Android 8 and up. Pick speech language in the app (default English). This APK is sideload, not Play Store.

  1. Download open-flow-0.1.7-debug.apk from Releases.
  2. Settings → Apps → Special access → Install unknown apps → Files → Allow.
  3. Open the file. Play Protect may warn. More details → Install anyway.
  4. Open Open Flow. Read the five short screens.
  5. Turn on Accessibility for Open Flow.
  6. If the switch is grey: Apps → Open Flow → ⋮ → Allow restricted settings → unlock → try Accessibility again.
  7. Allow the microphone. Battery is optional.
  8. Open Notes → tap the bubble → speak → tap again.
Samsung: Auto Blocker can block the install. Xiaomi / Oppo / Vivo: set battery to Unrestricted if the bubble dies after a minute.

Copy old text from History in the app. Updates: install the new APK over the old one.
