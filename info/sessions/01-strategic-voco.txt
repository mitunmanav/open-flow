~5 sec to summarize 5 pages

For MVP: skip LLM entirely. Use Android's built-in STT only. LLM is V2.

Item    Status

🔴 What's broken / unrealistic
1. <uses-permission> runtime mutation doesn't work
Reality: Android permissions must be declared in AndroidManifest.xml at install time. You cannot add INTERNET at runtime. Period. Workaround:

Declare INTERNET in manifest, but never make a network call unless the user opts in
Use NetworkSecurityConfig to block all domains by default, allowlist user-typed domains per feature
Privacy report shows "0 bytes sent" because no calls were made
2. createOnDeviceSpeechRecognizer() doesn't exist
Reality: Android API is SpeechRecognizer.createSpeechRecognizer() + RecognizerIntent.EXTRA_PREFERENCE_OFFLINE. Setting EXTRA_PREFERENCE_OFFLINE = 1 forces on-device mode IF user has downloaded the offline pack. There's no separate "on-device recognizer" factory. This is fine, just rename the code.

3. Audio in voice-typing mode can't be 100% guaranteed ephemeral
Reality: AudioRecord writes into a circular buffer. With SpeechRecognizer, the audio is consumed inside the system service — the system may log it for debugging. There's no API to guarantee zero retention. Better wording: "voice-typing audio is not intentionally persisted by open-flow; Android system may log it." Honest.

4. RECORDER_AUDIO is dangerous permission
On Android 12+, foreground mic access requires RECORD_AUDIO granted
Voice-typing keyboard needs it every session
Google's policy: "Apps must request RECORD_AUDIO only when actively used in foreground." IMEs count as foreground. ✓ OK for us.
5. "Encrypted at rest" needs Keystore key first
val masterKey = MasterKey.Builder(context)
    .setKeyScheme(MasterKey.KeyScheme.AES256_GCM)
    .build()
val ef = EncryptedFile.Builder(
    File(filesDir, "rec.m4a"), masterKey, AES256_GCM_HKDF_4KB
).build()
Works but: device with no hardware-backed Keystore (rare in 2026) falls back to software key. Note this in docs.

6. Qwen weights distribution
Apache-2.0 with use restrictions (notably: no use for improving other LLMs)
For redistribution in app: must include NOTICE + restrictions
For runtime download: user accepts terms
Easier: download on first use, store in app-private dir
7. Whisper.cpp NDK build
Need CMake + arm64-v8a, armeabi-v7a, x86_64 ABIs
Real build setup: 2-3 days yak-shaving, easy to get wrong
Consider: just bundle a prebuilt .so from official whisper.cpp releases (they publish these)
8. Foreground service + Android 14+
Android 14: foreground service type required (microphone)
Manifest: <service android:foregroundServiceType="microphone" />
Runtime: must declare type when starting
Real work, not optional
9. IME + Compose
IME service runs in its own window, not in app process
Compose in IME = tricky; many devs use Views for IME and Compose for app
Real work: decide Views or Compose for keyboard UI
10. F-Droid reproducibility
F-Droid builds with their keys, not yours
Must supply build.gradle with no proprietary deps
Verified: no Google Services, no Maps
But: prebuilt whisper.cpp .so files — must be reproducible or marked

### The trap

**Live STT + save audio at the same time is hard.**  
Mic is often exclusive. `MediaRecorder` + `SpeechRecognizer` together = classic fail (SO + Chromium issues).

**Workarounds (pick one):**
1. Record only → transcribe file after (easy, not “live”)
2. One `AudioRecord` pipeline → file + STT chunks (harder, correct)
3. STT live, no full audio file (keyboard path)

### Offline STT truth

- API exists: `createOnDeviceSpeechRecognizer()`, prefer-offline flags.[[1]](https://developer.android.com/reference/android/speech/SpeechRecognizer)
- Needs local engine + language pack on device.
- Accuracy often worse than cloud.
- Graphene / no GMS = may need Whisper/Vosk instead.

### “F-Droid empty” — outdated

FOSS already there:
- **Keyboards:** Whisper (F-Droid), Voxscribe, FUTO, Kõnele, Offline Voice Input  
- **Record + transcribe:** Notely Voice (F-Droid)  
- **Transcribe files:** Scrib  
- **Record only:** Fossify Voice Recorder  

Gap is **not zero**. Gap is **polished all-in-one: IME + recorder + search + encrypt + no account**.
