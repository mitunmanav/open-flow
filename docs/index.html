How you use it

  1. Install the APK. Turn on Accessibility. Allow the mic.
  2. Open a normal text field — not a password or bank app.
  3. Tap the bubble → speak → tap again. Words go in that field.

What stays on this phone

Keyboard
We sit on top. We do not replace Gboard.
History
Search, copy, share, JSON export. Copy lives here — not on the bubble.
Edits
“Strike that”, “X not Y”, lists, caps. Rules run on the phone.
Retention
Keep, wipe in 24 hours, or never save. No account. MIT. No ads.
Honest. INTERNET is declared. Open Flow does not use the network until you pick a cloud path or a model download. Speech still uses the phone’s system recognizer. On many phones that is Google, and audio can leave the device. Need voice to stay on this phone? Use a local Whisper or Vosk app — not this one, yet. Compare.

What it is not

  • Not Wispr Flow (closed, cloud).
  • Not an on-device Whisper model.
  • Not on F-Droid or Play yet.
  • Not a way around bank-app security warnings.
