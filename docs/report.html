How to report

Use GitHub. Do not put personal information in the report.

Open an issue Ask in Discussions

Include

  • Version (for example 0.1.5)
  • What you tapped and what you expected
  • Phone brand + Android version if you know
  • A cropped screenshot if it is a layout bug

Do not include

  • Passwords, medical notes, bank screens
  • Your name, email, or phone number
  • Device serials or full logs from other apps

Security hole: repo Security tab, not a public issue.
