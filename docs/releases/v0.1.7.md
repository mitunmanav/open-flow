# Open Flow 0.1.7

Talk, tap, text — into any app. Keep your keyboard. MIT.

## What’s new (since 0.1.5)

- **Your bubble** — colors, shape, your own icon, haptics. Stays up with the keyboard. Tile in Quick Settings.
- **Speak the edit** — “strike that”, “X not Y”, lists, caps. Cleanup runs on the phone.
- **Insights + export** — usage and JSON history stay on this device.
- **More languages** — Hindi, Indian English, and others in Settings.

Full list: [CHANGELOG.md](https://github.com/mitunmanav/open-flow/blob/main/CHANGELOG.md).

## Install

1. Download `open-flow-0.1.7-debug.apk` below.
2. Open it in Files. Play Protect “unknown” is normal.
3. Open the app. Follow the screens. Turn on Accessibility, then the mic.
4. If Accessibility is grey: App info → menu → **Allow restricted settings**.
5. Tap the bubble. Speak. Tap again.

More: [INSTALL.md](https://github.com/mitunmanav/open-flow/blob/main/docs/INSTALL.md) · [PRIVACY.md](https://github.com/mitunmanav/open-flow/blob/main/docs/PRIVACY.md).

Updating? Install this APK over the old one. If Accessibility greys out, allow restricted settings again.

## Limits

| Limit | Detail |
|-------|--------|
| **Install** | **Debug-signed** sideload. Play Protect may warn; tap **Install anyway**. |
| **Speech** | Uses the phone’s engine, which **may send audio to Google or the OEM**. |
| **Network** | INTERNET is **declared**; unused until you pick a cloud path or a model download. |
| **Stores** | **Not on Play or F-Droid yet**. |
| **Banks** | Bubble hides there. Those apps **may still warn**. That warning is theirs. |

Copy from History in the app — not from the bubble.

No personal data is included in this release.
