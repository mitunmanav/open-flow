Roadmap

Shipped first as a GitHub sideload. Dates are not promises.

Now (0.1.7)

  • Bubble + Accessibility insert. Not a keyboard. Stays while the keyboard is up.
  • Home · Dictionary · Snippets · Style. Listen Done. Press enter to send.
  • History copy/share. Cleanup levels. Optional cloud you pick.
  • INTERNET is declared; unused until you pick a cloud path.
  • Debug-signed APK on GitHub Releases.

Next

  • A real release keystore (this APK is debug-signed).
  • Install path tested from Files (Restricted Settings), not only USB.
  • Optional on-device model. Until then, audio privacy is not fully ours.
  • F-Droid when the signed build is clean enough.

Later, only if we mean it

  • Play Store (Accessibility declaration + video — hard, slow).
  • More languages.
  • Google 2026–27 developer verification on stock phones.

Not planned

  • Becoming a keyboard.
  • Accounts, ads, analytics.
  • Stripping declared INTERNET (it stays unused until you pick a cloud path).
  • Calling this a Wispr clone.

Talk about this in Discussions.
