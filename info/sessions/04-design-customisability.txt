# Wispr Flow **Desktop** features (Mac + Windows)

Sources: [Help Center nav map](https://docs.wisprflow.ai/articles/5096240724-navigating-the-wispr-flow-app-desktop-ios-and-android), [What is Flow](https://docs.wisprflow.ai/articles/2772472373-what-is-flow), [Features](https://wisprflow.ai/features), [What’s new](https://wisprflow.ai/whats-new), [Plans](https://docs.wisprflow.ai/articles/9559327591-flow-plans-and-what-s-included).

**Core model:** cloud STT · hotkey hold → speak → release → polish → paste. **No live words while talking.** Needs internet. Works in any text field (no plugins).

---

## 1. Dictation control (Flow Bar)

- Floating **Flow Bar** (bottom default; drag to bottom / left / right)
- Position saved; vertical when side-docked
- Center bubble: start · live **waveform** · Cancel / Stop
- **Push-to-talk** (hold) + **hands-free** (double-tap)
- Default hotkeys: Mac **fn** · Win **Ctrl+Win** (all rebindable)
- **Mouse Flow:** extra mouse buttons as PTT / toggle + optional “send”
- Language picker **on bar** (if 2+ langs set)
- Right-click menu: hide 1h · Settings · Mic · History · Paste last
- Optional: always show bar (Settings → System)
- Bar **hidden by default** on new installs

---

## 2. AI polish (while / after speak)

- Filler strip · auto punct · lists · backtrack / self-correct
- Context-aware names / jargon
- Whisper / quiet speech support (mic matters)
- **Auto Cleanup** levels: None · Light · Medium · High (Style tab)
- Undo AI edit from history (raw vs cleaned)
- Session length up to **~20 min** (warn near end)
- **No offline** dictation
