How to use it

You doWhat happens
Tap the bubbleListening starts
SpeakWords can show on the bubble if that chip is on
Tap againStop, clean, insert
HoldTalk while holding. Release inserts
XThrow away
Drag downHide 10 minutes. Shake to bring back

Dictionary vs snippet

Dictionary changes one word. Snippet pastes a whole block when you say an exact trigger.

If the bubble is gone

  1. Normal text field? Not a password?
  2. Keyboard up?
  3. Snoozed (dragged down)?
  4. Accessibility still on? Force-stop turns it off.
  5. Mic allowed?
